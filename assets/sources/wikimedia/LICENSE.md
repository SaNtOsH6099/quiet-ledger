## Licence summary

- CC0-1.0 / public domain: no attribution required (credited in the catalog anyway).
- CC-BY-3.0: attribution required — name, licence and source link travel in
  `attribution_text` in catalog-wikimedia.json.
- CC-BY-SA-3.0: attribution required AND derivatives stay CC-BY-SA.
  Only 2 files: golden-gate-bridge, burj-khalifa.
- No NC / ND / non-free files are in this library. If a licence changes,
  quarantine the file and re-check before any public release of the pack.
