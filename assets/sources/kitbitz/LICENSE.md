## Notes

  2,409 Kitbitz illustrations; the GitHub repo (the bulk source actually used)
  contains 2,414 SVG files across 15 kits. The repo is the author's own
  asset repository and was preferred over per-file downloads.
- 146 of the 2,414 files were rejected during curation (141 contain embedded

  flattening); see
  `~/workspace/quiet-ledger/assets/kitbitz-rejected.json`. 2,268 kept.
- Kitbitz's author is Sjoerd Heijsman (per secondary coverage); the catalog
  leaves `source_author` blank because the primary sources checked (repo
  README, kitbitz.art FAQ/license pages) do not name an author.
