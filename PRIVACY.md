# Privacy Policy for quiet-ledger

Last updated: 2026-11-06

quiet-ledger is a personal automation tool. It reads a small task queue from the
owner's Google Drive, generates a short video from that task, and writes the
finished video back to the same Google Drive folder.

## Data accessed

The app uses the Google Drive API with the owner's own Google account. It
accesses only the Drive folder the owner chooses for the queue and the finished
videos. It does not read any other files in the owner's Drive.

## Data use and sharing

The app does not sell, share, or send the owner's data to any third party. The
finished videos are stored only in the owner's Google Drive. No personal data
is collected, stored, or transmitted beyond what is needed to read the queue
and write the finished videos.

## Contact

Questions about this policy can be raised through the quiet-ledger repository
on GitHub.
